# Question-writing policy

The AWS Certification Program Agreement forbids sharing live exam content. Every question in this repository must be
original.

## Rules

1. **Write from the docs, not from memory of an exam.** Base each question on AWS documentation, and link it in
   `sources`. Never reproduce, paraphrase or reconstruct a question seen on a real AWS exam, and never use "brain
   dump" sites or question banks from other vendors.
2. **Explain every option.** Each option has a `why`, including the correct ones. A wrong option's `why` says what
   would have to be true for it to be right.
3. **Match the exam's format.** A multiple-choice question has one correct option out of four. A multiple-response
   question has two or more correct out of five or more, and says how many to choose.
4. **One idea per question.** Test the concept the page teaches, not trivia or a trick of wording.
5. **Distractors must be plausible.** Use the mistakes people actually make, which are often on the page's
   "Common mistakes" table.
6. **Don't refer to option letters** in a `why` or `explanation`. The practice exam shuffles the options.
7. **Tag accurately.** `services`, `exam_domains` and (once published) `tasks` decide where a question appears and
   how it counts toward coverage.

## Review

An exam-alignment reviewer confirms that each question tests its tagged task statement and that the sourced facts
are still true. Questions are reviewed with the page they belong to, every 90 days.
